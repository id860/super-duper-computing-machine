# Security Policy

## Секреты

Никогда не добавляйте токены, пароли администратора и `.env` в Git. Все секреты задаются переменными окружения.

## Production checklist

- установить длинный случайный `ADMIN_PASSWORD`;
- включить TLS через reverse proxy или хостинг;
- добавить CAPTCHA и подтверждение почты;
- ограничить размер запросов на уровне reverse proxy;
- хранить данные на постоянном диске;
- настроить резервные копии `DATA_DIR`;
- заменить локальные сессии на Redis при нескольких экземплярах сервера.

## Сообщение об уязвимости

Не публикуйте эксплойты в открытых issues. Передайте владельцу репозитория описание, шаги воспроизведения и ожидаемое влияние приватным каналом.
