# PixelFront Worlds

Автономная многопользовательская пиксельная платформа: один официальный **бесконечный** мир с честной прогрессией и настраиваемые миры сообщества без влияния на глобальный рейтинг.

## Что нового в v3

- **Бесконечный холст** — официальный мир бесконечный (виртуальный лимит 100 000 × 100 000).
- **Зона спавна 1000 × 1000** — обозначена пунктирной синей рамкой; пиксели внутри дают двойной XP.
- **Флэт-минимализм** — белый фон, один акцентный синий цвет `#2563eb`, без градиентов и теней.
- **Пиксельные иконки инструментов** — нарисованы на canvas 9 × 9 вместо юникод-символов.
- **Мощная оптимизация рендера**:
  - разрежённый рендер только закрашенных пикселей с отсечением по вьюпорту — `O(пиксели)` вместо `O(площадь)`, лаги устранены;
  - коалесинг кадров через `requestAnimationFrame`;
  - офскрин-буфер миникарты, пересобирается только при изменении пикселей.
- **Полная админ-панель** — изменение каждого параметра мира, управление игроками прямо из интерфейса.

## Возможности

- регистрация и вход по нику/паролю, хеширование `scrypt`;
- официальный холст, энергия, XP, уровни, достижения и топ;
- пользовательские миры со своими размерами, КД и энергией;
- защищённые арты в мирах сообщества;
- локальные чаты и обновления через Server-Sent Events;
- жалобы, rate limits и серверная проверка всех действий;
- JSON-персистентность без внешних зависимостей;
- Docker, GitHub Actions и интеграционные API-тесты.

## Локальный запуск

```bash
cp .env.example .env
# Задайте ADMIN_NICK и ADMIN_PASSWORD в .env
set -a && source .env && set +a
npm start
```

Откройте `http://localhost:3000`.

## Docker

```bash
cp .env.example .env
# Обязательно установите длинный ADMIN_PASSWORD
docker compose up -d --build
```

## Тесты

```bash
npm test
```

Имеются четыре набора:

| Файл | Что проверяет |
|---|---|
| `test/core.test.mjs` | статика v1: изоляция прогрессии, отсутствие токенов |
| `test/api.test.mjs` | интеграция v1: регистрация, пиксели, чат |
| `test/core-v3.test.mjs` | статика v3: бесконечный мир, зона спавна, rAF, пиксельные иконки |
| `test/api-v3.test.mjs` | интеграция v3: бесконечный холст, XP в зоне спавна, изоляция, безопасность, админка |

## Развёртывание

В репозитории есть `render.yaml`. При создании Render Blueprint задайте секреты `ADMIN_NICK` и `ADMIN_PASSWORD` и подключите постоянный диск. Также проект можно запускать на любом VPS через Docker Compose.

GitHub Pages не подходит: игре нужен постоянно работающий Node.js-сервер.

## Правило прогрессии

XP, достижения и глобальный рейтинг начисляются только при `world.type === "official"`. Пиксели в зоне спавна (0–0 999, 0–0 999) дают двойной XP. Пиксели пользовательских миров учитываются отдельно и не могут использоваться для накрутки.

## Перед большой нагрузкой

Перенесите данные в PostgreSQL, сессии и rate limits — в Redis, карту разделите на чанки с пространственным индексом, добавьте CAPTCHA, подтверждение почты, CDN и сервис проверки изображений.
