# PixelFront Worlds

Автономная многопользовательская пиксельная платформа: один официальный мир с честной прогрессией и настраиваемые миры сообщества без влияния на глобальный рейтинг.

## Возможности

- регистрация и вход по нику/паролю, хеширование `scrypt`;
- официальный холст, энергия, XP, уровни, достижения и топ;
- пользовательские миры со своими размерами, КД и энергией;
- защищённые арты в мирах сообщества;
- локальные чаты и обновления через Server-Sent Events;
- жалобы, rate limits и серверная проверка всех действий;
- JSON-персистентность без внешних зависимостей;
- Docker, GitHub Actions и интеграционные API-тесты.

## Локальный запуск

```bash
cp .env.example .env
set -a && source .env && set +a
npm start
```

Откройте `http://localhost:3000`.

## Docker

```bash
cp .env.example .env
# Обязательно установите длинный ADMIN_PASSWORD
docker compose up -d --build
```

## Тесты

```bash
npm test
```

Тесты проверяют регистрацию, официальный прогресс, изоляцию миров сообщества, защиту артов, чат и отсутствие токенов в исходниках.

## Развёртывание

В репозитории есть `render.yaml`. При создании Render Blueprint задайте секреты `ADMIN_NICK` и `ADMIN_PASSWORD` и подключите постоянный диск. Также проект можно запускать на любом VPS через Docker Compose.

GitHub Pages не подходит: игре нужен постоянно работающий Node.js-сервер.

## Правило прогрессии

XP, достижения и глобальный рейтинг начисляются только при `world.type === "official"`. Пиксели пользовательских миров учитываются отдельно и не могут использоваться для накрутки.

## Перед большой нагрузкой

Перенесите данные в PostgreSQL, сессии и rate limits — в Redis, карту разделите на чанки и добавьте CAPTCHA, подтверждение почты, CDN и сервис проверки изображений.
